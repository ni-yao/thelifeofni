Website privacy

Effective October 27, 2026.

This website uses Cloudflare Web Analytics to measure page views and page performance. Cloudflare hosts the site and processes ordinary network information to deliver and protect it.

A first-party counter records page views, engaged reading, downloads, page errors, and clicks on professional, contact, and other external links. Counts include the page, destination category, link placement, broad traffic source, and short source, medium, or campaign labels from tagged links. Page errors are counted only by broad type, such as a script or image that failed to load; error messages and file names are not recorded. Email addresses, message contents, full referring URLs, and the rest of the query string are not included.

The counters use no cookies, browser storage, visitor identifiers, session identifiers, or fingerprinting. Daily totals are kept for up to two years. A short-lived hash of the request address helps limit automated abuse and is not stored with the totals. The first-party counter respects Global Privacy Control and Do Not Track signals. You can also block analytics scripts or requests using your browser.

Cloudflare processes the network requests under its privacy policy. Google Fonts delivers the site's typefaces and may receive ordinary request information. External websites have their own privacy practices.

If you contact me, I use the information you provide to respond. For privacy questions, use the contact links on the home page.
